# remove-sharpuse
A utility to expand all uses of #use in an OCaml program

## Install

Implemented versions: 4.14.2 (works for 4.14.3, too), 4.12.0,
4.11.0-alpha1, 4.04.0.

```txt
opam pin add remove-sharpuse https://github.com/kenichi-asai/remove-sharpuse.git#4.14.2
```

## Usage

```
$ remove-sharpuse filename.ml
```
